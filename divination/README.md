# 大乱斗卦象占卜 · ARAM 玄学指引

趣味向 LOL 大乱斗（ARAM）卦象占卜网页程序。点击「焚香起卦」，六爻自下而上翻落成象，随机起出六十四卦之一，解读当局运势与对局提示。

> 仅供游戏娱乐，非现实占卜。玄学有风险，上分需谨慎。

## 使用

直接打开 `index.html` 即可使用（单文件、零依赖），也可通过 GitHub Pages 在线访问。

## 功能

- **焚香起卦**：六爻逐条翻落动画，随机起出六十四卦，展示卦符、卦名、吉凶徽章与三段解读（卦义 / 对局提示 / 吉凶预示）
- **皮肤颜色高亮**：解读中的皮肤颜色词（金色、冰蓝、电光紫等）自动按对应色高亮，方便对照场上英雄
- **八卦方位图**：八卦 · 元素 · 颜色 · 大乱斗地图方位对照表与皮肤代替机制
- **六十四卦总览**：64 张卦卡，悬停显示吉凶，点击细读任意一卦

## 判读逻辑（摘要）

1. 优先看英雄本身技能属性，卦象元素与场上英雄元素对上，预兆落在该英雄身上。
2. 阵容没有对应元素英雄时，以皮肤主色调代替征兆对象。
3. 吉兆：该对象是我方核心；凶兆：该对象是敌方主要威胁。
